# P1 incident execution

## Purpose

This runbook provides the repeatable execution flow for a Priority 1 incident. It is intended for teams that need a clear sequence from declaration through stabilization and closure.

## Sequence

1. declare incident and assign roles
2. open bridge and written source of truth
3. confirm scope, impact, and dependencies
4. isolate blast radius and apply containment
5. coordinate technical triage and decision-making
6. communicate updates on a fixed cadence
7. verify recovery and document decisions
8. hand off to problem management and post-incident review

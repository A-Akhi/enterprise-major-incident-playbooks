# Documentation

This repository uses a layered structure to separate operational guidance from governance and reusable templates.

## Primary structure

- [playbooks/](../playbooks/README.md): incident response, security, and continuous improvement workflows
- [governance/](../governance/README.md): CAB, reliability, and operational policy guidance
- [templates/](../templates): reusable forms and standard templates

## Secondary compatibility folders

The legacy folders (`Incident Management`, `Change Management`, etc.) are preserved for compatibility with existing references and bookmarks.

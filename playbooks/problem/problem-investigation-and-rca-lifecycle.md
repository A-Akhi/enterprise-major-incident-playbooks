# Problem investigation and RCA lifecycle

Problem management prevents recurring failures by converting incidents into structured corrective action.

## Lifecycle

1. Create a problem record after incident closure.
2. Investigate the root cause and contributing conditions.
3. Determine whether a temporary workaround is required.
4. Publish a known-error record if relevant.
5. Drive permanent remediation and close the loop.

## Prioritization

| Impact | Recurring | Isolated |
| --- | --- | --- |
| High | P1 | P2 |
| Low | P3 | P4 |

## Required outputs

- timeline and service impact summary
- root-cause analysis and 5-Whys summary
- risk-based prioritization
- action owner and target date
- known-error or workaround documentation if applicable
